# Fonts of the generated CV

Latin Modern Sans (regular, oblique, bold, bold oblique), version 2.004, by GUST e-foundry:
<https://www.gust.org.pl/projects/e-foundry/latin-modern>.

It is the typeface of the LaTeX `moderncv` template the CV came from, and
`src/lib/cv/CvDocument.tsx` embeds it in the PDF.
